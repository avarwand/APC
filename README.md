# Picture Converter

</div>

A **modern GUI tool** for **batch converting pictures** between many formats and for **compressing pictures to a target file size**, with precision, speed, and safety.

> _No command line | No risk | Full control_

---

## Features

- **Batch conversion** of any mix of picture formats in one operation
- **Wide format support**: standard, RAW camera, HDR/scientific, and game-texture pictures
- **Import by click or drag & drop**, files or whole folders, searched to any depth
- **Keeps your folder structure** in the output, if you want it
- **Compression Mode**: shrink pictures to a maximum file size at the best quality that fits
- **Best possible quality**: lossless wherever the format allows it, transparency preserved
- **Safe by design**: originals are never modified, and no output is ever overwritten
- **Fast**: parallel background processing with a progress bar, the window never freezes
- **Clean dark-mode interface**, no technical knowledge required

---

## Supported Formats

| | Formats |
|---|---|
| **Input** | JPEG, JFIF, PNG, BMP, WebP, TIFF, HEIC, HEIF, AVIF, JXL, ARW, CR2, CR3, DNG, NEF, ORF, EXR, FITS, DDS, TGA |
| **Output** | JPEG, PNG, BMP, WebP, TIFF, TGA, DDS |

## How to Use

1. Download the latest version from the [Releases](https://github.com/avarwand/APC/releases) page and unzip it (run the installer for the installer version)
2. **Import** pictures or folders by click or drag & drop
3. Choose the **Output Format** and the **Output Path**
4. Click **Start Conversion**, or **Start Compression** to shrink files in their own format
5. **Done!**

Full documentation is in the **[APC Wiki](https://github.com/avarwand/APC/wiki)**.
